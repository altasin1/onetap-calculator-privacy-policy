Section 03

Advertising — Google AdMob

OneTap Calculator is a free app supported by advertising. We use Google AdMob to display ads. This section explains how AdMob works and what data it may collect.

📋 Types of Ads in OneTap Calculator
Ad Type Placement Frequency
🖼️ Banner Ads Bottom of each calculator screen (above navigation) Always visible — non-intrusive
📱 Interstitial Ads Between major screen transitions Every 3–4 navigations (not every time)
🎥 Rewarded Ads Optional — to unlock features (e.g., CSV export, themes) User-initiated only

Google AdMob may collect the following information for ad personalization:

  • Advertising ID (IDFA/GAID): A resettable device identifier used to serve relevant ads.
  • IP Address: Used for general location-based ad targeting (country/region level).
  • App Usage Data: How you interact with ads (clicks, views) — fully anonymized.
  • Device Information: Device type, OS version — used for ad compatibility.
✅ Opt-Out of Personalized Ads You can opt out of personalized advertising at any time:

📱 Android: Settings → Google → Ads → "Opt out of Ads Personalization"
🍎 iOS: Settings → Privacy → Tracking → Disable tracking for OneTap Calculator

You will still see ads, but they will not be personalized based on your interests.

Google AdMob's data practices are governed by Google's Privacy Policy:
🔗 https://policies.google.com/privacy

Section 09

Data Security

Protecting your data is our top priority. Here are the security measures implemented in OneTap Calculator:

  • ✅
    Local-Only Storage: All calculation data, history, and settings are stored only on your device using encrypted local databases (Hive/Isar). No data is transmitted to external servers.
  • ✅
    API Key Protection: Your currency API keys are stored in the device's secure local storage and are never logged, shared, or transmitted anywhere except to the API provider you choose.
  • ✅
    HTTPS Only: All network requests (currency API calls and AdMob) use HTTPS encrypted connections — your data is protected in transit.
  • ✅
    No Backend Server: OneTap Calculator has no backend server. There is no central database that stores your information — eliminating the risk of server-side data breaches.
  • ✅
    Regular Updates: We regularly update the app to patch security vulnerabilities and maintain compatibility with the latest OS security standards.
⚠️ Device Security Reminder While we implement strong in-app security, the overall security of your data also depends on your device's security. We recommend enabling screen lock, keeping your device OS updated, and avoiding installing apps from untrusted sources.
